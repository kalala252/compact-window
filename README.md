# Compact Window

Chrome のウィンドウを1つだけ選んで、タブバーとアドレスバーを隠した表示に切り替える拡張機能です。macOS の Chrome にある「全画面表示でツールバーを常に表示」（`⌘⇧F`）の切り替えは全ウィンドウに効きますが、この拡張機能は操作したウィンドウにしか効きません。

## 仕組み

Chrome の拡張機能 API には、通常ウィンドウのツールバーを直接隠す機能がありません。そこで、表示中のタブを同じ位置・サイズのポップアップ型ウィンドウ（`chrome.windows.create({ type: "popup" })`）へ移しています。ポップアップ型ウィンドウにはタブバーも編集できるアドレスバーもないため、その分だけページの表示領域が広がります。

元に戻すと、タブは元のウィンドウの元の位置へ戻ります。タブを移動させているだけなので、入力中のフォームやスクロール位置はそのまま残ります。元のウィンドウがすでに閉じている場合は、新しい通常ウィンドウとして開き直します。

## インストール

1. このリポジトリをクローンするか ZIP でダウンロードする
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

## 使い方

ツールバーの拡張機能ボタンを押すと、そのウィンドウのタブがコンパクト表示に切り替わります。ポップアップ型ウィンドウには拡張機能ボタンが表示されないため、元に戻すときはキーボードショートカットか右クリックメニューを使ってください。

| 操作 | 方法 |
| --- | --- |
| コンパクト表示にする | 拡張機能ボタン / `Control + Shift + F`（Windows・Linux は `Ctrl + Shift + F`） / 右クリック →「コンパクト表示の切り替え」 |
| 元に戻す | `Control + Shift + F` / 右クリック →「コンパクト表示の切り替え」 |

ショートカットは `chrome://extensions/shortcuts` で変更できます。

## 制限

コンパクト表示になるのは、操作したときに表示していたタブ1枚だけです。ポップアップ型ウィンドウにはタブを切り替える手段がないため、ウィンドウ内の全タブをまとめて移す方式にはしていません。

macOS では、ポップアップ型ウィンドウにもタイトルバーと URL を表示する細い帯が残ります。`chrome://` で始まるページなど拡張機能が動作しないページでは右クリックメニューが出ないため、ショートカットを使ってください。

## 権限

| 権限 | 用途 |
| --- | --- |
| `tabs` | タブを元のウィンドウへ戻せなかったときに、URL を読んで開き直す |
| `contextMenus` | 右クリックメニューに切り替え項目を追加する |
| `storage` | どのポップアップ型ウィンドウがどのウィンドウから来たかを、ブラウザを閉じるまで記録する（`chrome.storage.session`） |

外部への通信は行いません。
